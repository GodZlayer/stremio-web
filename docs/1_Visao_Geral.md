# Visão Geral do Projeto Stremio

Este documento fornece uma visão geral de alto nível da aplicação web Stremio.

## Propósito

O Stremio é uma aplicação de hub de mídia que permite aos usuários descobrir, organizar e assistir a conteúdo de vídeo de várias fontes, incluindo filmes, séries, TV ao vivo e canais de vídeo.

## Tecnologia

A aplicação é construída como um single-page application (SPA) usando as seguintes tecnologias principais:

*   **React:** Uma biblioteca JavaScript para construir interfaces de usuário.
*   **Webpack:** Um empacotador de módulos para compilar e agrupar os assets da aplicação (JavaScript, CSS, imagens).
*   **Babel:** Um compilador de JavaScript que permite o uso de recursos modernos da linguagem.

O projeto está configurado para desenvolvimento e produção, com scripts para iniciar um servidor de desenvolvimento, construir a aplicação e executar testes.
